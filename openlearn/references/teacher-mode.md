# Teacher mode

Teachers want classroom-ready material they can trust, edit and print. The same quality
rules apply (quiz-design.md, flashcards.md, lessons-and-examples.md), with these additions.

## Ask (only if not given)
Grade/level, board or curriculum, class period length, and what they need: worksheet,
quiz/test paper with marks, lesson plan, homework, exit tickets, or differentiated sets.

## Worksheets and test papers
- Header: title, class, subject, chapter, time allowed, total marks, name/date lines.
- Sections by question type, each with instructions and marks per question.
- Spread across Bloom's levels; label difficulty in the teacher copy only.
- **Answer key and marking scheme on a separate page** (or separate file), with model
  answers and the key points that earn each mark.
- If they name a board pattern (e.g. CBSE: MCQ, assertion–reason, short answer, long
  answer, case-based), follow it.

## Differentiated sets
Produce three versions on the same objectives:
- **Support:** more scaffolding, worked example at the top, simpler language, sentence
  starters.
- **Core:** standard.
- **Extension:** more application/analysis, open-ended challenge question.

## Lesson plan
Objectives → prerequisite check (2 quick questions) → hook → direct instruction in chunks
with checks for understanding → worked example → guided practice (faded) → independent
practice → exit ticket (3 questions) → homework (spaced: include 1–2 questions from an
earlier chapter). Include timings that fit the period length and the common misconceptions
to watch for.

## Files
If they want something printable or editable, produce it as a document (or the file
format they name) rather than only chat text, with the answer key separated.
